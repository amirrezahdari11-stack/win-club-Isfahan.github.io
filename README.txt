WIN - نسخه‌ی وب‌اپ (برای آیفون و هر مرورگر)

آپلود:
  همه‌ی فایل‌های این پوشه را مستقیم داخل public_html (ریشه‌ی سایت) هاست بریز. آدرس سایت باید HTTPS باشد.

نصب روی آیفون:
  1) لینک سایت را در Safari باز کن (نه داخل مرورگر تلگرام یا اینستاگرام).
  2) دکمه‌ی Share ← Add to Home Screen ← Add.
  3) یک بار اپ را از روی آیکون باز کن (با اینترنت). از آن به بعد بدون اینترنت هم باز می‌شود.

نصب روی اندروید (Chrome): منو ← Install app.

فونت (اختیاری): فایل Vazirmatn variable با نام vazirmatn.woff2 را کنار index.html بگذار. بدون آن، فونت خود گوشی استفاده می‌شود.

آپدیت: index.html را عوض کن و دوباره آپلود کن. نسخه‌ی جدید بار بعدی که اپ را باز می‌کنند نمایش داده می‌شود (گاهی یک بار بستن و باز کردن لازم است).

سناریوی مشترک برای همه:
  - با کد: در اپ «اشتراک‌گذاری با کد» را بزن و کد را برای دوستانت بفرست. آن‌ها در «+ سناریوی جدید» کد را می‌چسبانند.
  - کاتالوگ مشترک: سناریو را بساز، «کپی JSON برای کاتالوگ مشترک» را بزن و متن را داخل آرایه‌ی scenarios.json (کنار index.html) بگذار و فایل را دوباره آپلود کن. همه‌ی کاربران بار بعدی که اپ را با اینترنت باز کنند سناریو را می‌گیرند و برای حالت آفلاین نگه می‌دارند.

سناریوی پیش‌فرض:
  داخل index.html آرایه‌ی const DEFAULTS=[]; هست. هر سناریویی که در آن بگذاری برای همه‌ی کاربران، مثل سناریوهای اصلی، در لیست می‌آید و حذف‌شدنی نیست. قالبش را دکمه‌ی «کپی JSON (برای افزودن به پیش‌فرض‌ها)» در اپ می‌دهد.

اشتراک سناریو بدون سرور (با GitHub Pages):
  1) این پوشه را روی GitHub Pages (مخزن Public) بگذار.
  2) سناریو را در اپ بساز و «کپی کاتالوگ کامل (برای scenarios.json)» را بزن.
  3) در GitHub فایل scenarios.json را باز کن، با آیکون مداد ویرایش کن، کل محتوا را با متن کپی‌شده جایگزین کن و Commit بزن.
  4) هر گوشی بار بعدی که اپ را با اینترنت باز کند، سناریو را خودکار می‌گیرد.
